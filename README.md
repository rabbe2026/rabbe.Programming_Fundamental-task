# Java Tasks

Four small Java programs.

| File | Description |
|------|-------------|
| `Task1.java` | Weeks needed to save for a laptop |
| `Task2.java` | Count even and odd numbers until 0 is entered |
| `Task3.java` | Count days with negative temperature (reads `data.txt`) |
| `Task4.java` | Count numbers smaller than their left neighbor (reads `duomenys.txt`) |

## Run

```bash
javac Task1.java Task2.java Task3.java Task4.java

java Task1
java Task2
java Task3
java Task4
```

Run Task3 and Task4 from the folder that contains `data.txt` / `duomenys.txt`.
